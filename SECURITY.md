# Security Policy

## Upstream security policy

Termux security guidance and vulnerability reporting are maintained at:
https://termux.dev/security

## Community-build guidance

This repository is a focused community build. Prefer APKs produced by this repository's GitHub Actions or releases, and verify SHA-256 checksums when published.

Do not install APKs from unknown mirrors or untrusted links.

## Never commit secrets

Do not commit API keys, access tokens, private certificates, signing passwords, credentials, or other sensitive material.

## Reporting

For vulnerabilities affecting upstream Termux, follow the upstream security policy above. For issues introduced specifically by this repository, use GitHub's private security reporting mechanism when available; otherwise report a minimal issue without sensitive details.
